# 智闪卡 · 基于前端的 AI 辅助知识点闪卡学习工具

> 《人工智能基础与应用》课程作业作品
> 纯前端实现（HTML + CSS + 原生 JavaScript），无需后端服务器，可直接部署到 GitHub Pages。

---

## 一、项目介绍

「智闪卡」是一个面向课程学习场景的智能闪卡工具。它将「主动回忆 + 间隔重复」的记忆科学方法做成网页应用，并引入两级 AI 能力：

1. **本地智能引擎**（默认可用）：基于中文自然语言规则，从教材段落中识别「X 是 Y / X 指 Y」等定义句式，自动出题、生成填空卡与提示；
2. **大模型生成**（可选扩展）：填入兼容 OpenAI Chat Completions 格式的 API Key 后，可调用大语言模型生成更高质量的问答卡片。

作品重点体现了人工智能课程中的**知识表示、规则推理、智能调度（SM-2 算法）与生成式 AI 应用**等核心概念。

## 二、功能说明

| 模块 | 功能 |
| --- | --- |
| 卡组管理 | 新建 / 编辑 / 删除卡组，一键加载示例卡组，展示卡片数、待复习数、掌握进度 |
| 卡片管理 | 手动添加 / 编辑 / 删除卡片，关键词搜索，显示熟练度标签与复习次数 |
| 学习中心 | 卡片翻转动画、四档记忆评分（忘记了 / 有印象 / 记住了 / 太简单）、快捷键操作、本轮学习小结 |
| 智能调度 | SM-2 间隔重复算法：根据评分动态调整简易度系数与下次复习间隔；答错 1 分钟后重现 |
| AI 辅助出题 | 粘贴教材文本 → 本地规则引擎或大模型自动生成候选卡片 → 勾选导入 |
| 学习统计 | 累计复习次数、正确率、连续学习天数、熟练度分布、各卡组进度、近 7 天复习柱状图 |
| 数据管理 | localStorage 本地持久化、JSON 导入导出、一键清空 |

## 五、运行方法

### 方法 1：直接打开
双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开即可使用。

### 方法 2：本地服务器（推荐，与线上环境一致）
```bash
# 在项目根目录执行
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

首次使用时点击右上角「加载示例卡组」，即可获得 10 张人工智能核心概念卡片用于体验。也可以进入「设置 → 导入数据」，选择仓库中 `data/sample-decks.json` 文件导入同一份示例卡组。

### AI 功能配置（可选）
进入「设置」页面，填写以下信息后可使用大模型生成卡片：

- **API 地址**：`https://api.deepseek.com/v1/chat/completions`（或其他兼容 OpenAI 格式的接口）
- **API Key**：你的密钥（仅保存在浏览器本地，不会上传）
- **模型名称**：如 `deepseek-chat`

填写后点击「测试连接」验证，再在 AI 生成弹窗中选择「大模型生成」。不配置时默认使用本地智能引擎，功能完全可用。

## 六、GitHub Pages 部署步骤

对应课堂幻灯片「实战案例四：个人网站开发与部署」的操作流程：

1. **创建仓库**：登录 GitHub → 点击「New repository」→ 填写 Owner 与 Repository name（名称需唯一，例如 `ai-flashcard-你的学号`）→ 选择 **Public** → 点击 **Create repository**。

2. **上传文件**：在仓库页面的 **Quick setup** 区域点击 **uploading an existing file**（上传现有文件），把本项目的 `index.html`、`css/`、`js/`、`screenshots/`、`README.md` 全部拖入上传区，填写提交信息后点击 **Commit changes**。

3. **开启 Pages**：进入仓库 **Settings** → 左侧 **Pages** → Build and deployment 选择 **Deploy from a branch** → Branch 选择 `main`、目录选择 `/ (root)` → 点击 **Save**。

4. **获取链接**：等待 1~2 分钟刷新页面，顶部会出现 `https://你的用户名.github.io/仓库名/` 的访问链接。打开确认页面可正常访问。

> ⚠️ 作业要求：网页项目必须部署到 GitHub Pages 且链接可正常访问，**仅上传代码不视为完成部署**。提交时务必附上这个可访问链接。

## 七、核心算法说明（SM-2 摘要）

卡片维护三个状态变量：简易度系数 `ease`（初始 2.5）、复习间隔 `interval`（天）、连续正确次数 `repetitions`。

- 评分 `q ≥ 3`（记住了）：间隔按 **1 天 → 6 天 → interval × ease** 递增，`repetitions + 1`；
- 评分 `q < 3`（忘记了）：间隔归零、1 分钟后重现，`repetitions = 0`；
- 每次评分后更新 `ease = ease + (0.1 − (5−q) × (0.08 + (5−q) × 0.02))`，并保证 `ease ≥ 1.3`。

该算法使学习间隔随记忆牢固程度动态拉长，符合艾宾浩斯遗忘曲线规律，是本作品「智能化」的核心体现。
