关于本作品

「智闪卡」是《人工智能基础与应用》课程作业作品。采用纯前端技术（HTML + CSS + 原生 JavaScript）实现，无需服务器即可运行，可一键部署到 GitHub Pages。核心 AI 元素包括：模拟人类记忆的 SM-2 间隔重复调度算法、基于自然语言规则的本地智能出题，以及可接入大模型的生成式 AI 扩展接口。
